## Local Development

To run this website locally with live-reloading:

1. **Prerequisites**: Ensure you have [Node.js](https://nodejs.org/) and npm installed.
2. **Run Server**: Execute the following command in the root of the repository:
   ```powershell
   npx --yes live-server
   ```
3. **View Site**: The site will be served at `http://127.0.0.1:8080` and will automatically refresh when you save changes.
